# Exiled Kingdoms 人物档案（翻译口吻基准）

## 可招募同伴

### 阿达昂 Adaon（男 / 法师）
- **身份**：旅途相遇的法师，开局教程人物；来历成谜，主线剧情核心人物
- **口吻**：友好健谈、学者气质、偶有自嘲；对自身过去避而不谈
- **称呼玩家**：朋友（friend）
- 参考句："你好，朋友，我叫阿达昂，我正沿这条路往西走。你也往那边去吗？"

### 格里森达 Grissenda（女 / 战士）
- **身份**：王桥镇的雇佣兵，豪爽务实
- **口吻**：活泼直率、爱开玩笑、忠义；佣兵气的俚语
- **称呼玩家**：老板（boss）
- 参考句："嘿，老板，有什么事？""正玩得开心呢！听你的，老板。"

### 赫尔嘉 Hirge（女 / 牧师）
- **身份**：三神教会女祭司，曾在自由镇教会任职；有预知异能（visions）
- **口吻**：庄重、虔诚、言辞文雅带古风；自信甚至略显居高临下，但对玩家忠诚
- **称呼玩家**：直呼 "you"，不用昵称
- 参考句："我的异象又一次应验了。要我与你同行吗？""我起过誓：无论顺境逆境，你的路就是我的路。"

## 重要 NPC（按剧情重要度）

### 特雷马丹 Tremadan
古代传奇大法师，三神信仰历史的关键人物，多出现在典籍/幻象/遗迹对话中——语体偏古雅书面。

### 莱尔特斯 Laertes
法师公会重要人物（各城法师塔导师线），措辞严谨、职业化。

### 阿玛丽莎 Amarisa
女性剧情人物（I3 方舟线核心），具体口吻以 IM_/I3_ 对话为准。

### 杜雷马斯 Duremas
死灵法师（D9 任务线），阴郁傲慢。

### 阿泽兰 Azeran
法师（F6/H10 线），反派气质。

### 特里克斯 Trix
盗贼（E10 塔），市井油滑。
